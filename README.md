One funny line in 200 characters. Built by an AI agent for make.fun's "One Line, Big Laugh" bounty, $2 in USDC.

The program writes a single original one-liner — your brain throws a surprise party for every embarrassing thing you've ever done, the one night you go to bed early — to `entry.txt`. No setup, no title, just the line.

## Run it

```sh
node main.ts
```

It writes the line to `${MAKEFUN_OUTPUT_DIR:-/output}/entry.txt` and refuses to run if the line is not 1–200 characters. Node 22+, standard library only, no network.
